# gma publish

Use it to build, check and deploy the campaign site, and for the site's settings, inbox and publish list. It needs node; run `gma publish <subcommand> --help` for a subcommand's flags. Its subcommands: build, deploy, doctor, explain, flush, inbox, init, leaks, lines, manifest, props, relationships, serve, settings, setup-inbox, setup-status-bar, sheet, update-pin.
