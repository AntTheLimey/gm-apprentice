# gma vault-search

Use it to find which notes mention something, ranked, before reading any of them. It needs the vault and the search words; it reads only.

Ranked vault search.

```text
gma vault-search <vault> <query> [options]
```

| Argument | Value | Help |
|---|---|---|
| `<vault>` |  | the vault folder |
| `<query>` |  | the search words |
| `--limit` | `LIMIT` | the most results to print |
| `--context` |  | show each result's best-matching line |
